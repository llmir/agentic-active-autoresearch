# Visual asset provenance

All four repository images are original AI-generated artwork created with OpenAI's built-in
Image2 tool. They contain no third-party logo, watermark, copied interface, real API key, personal
path, dataset row, or benchmark result. Generated PNG sources stay outside Git; reviewed JPEGs are
compressed below the repository's 1 MB pre-commit limit.

## Hero

`agentic-active-autoresearch-hero.jpg` (2172 × 724) was generated on 2026-08-17 and
iteratively edited for GitHub thumbnail legibility. Its final refinement prompt preserved a
five-stage scientific closed loop, dark navy/cyan/violet lighting, a coral selected molecule, and
crisp arrows while reducing peripheral molecular and mesh clutter. The prompt prohibited text,
logos, watermarks, UI, extra stages, and people.

## Architecture system map

`agentic-active-autoresearch-architecture.jpg` (1536 × 1024) was regenerated and corrected on
2026-08-21 after the safe-checkpoint and five-paradigm implementation landed. A user-supplied
academic framework diagram informed only the high-level composition: numbered modules, central
engine, explicit inner search, baseline rail, and audit dashboard. Its branding, text, identifiers,
hashes, and visual assets were not copied.

The generation prompt required ten unique modules and these implementation facts:

- CUDA/MPS GPU training and a separately labeled CPU RF baseline;
- a labeled-only sequential inner loop and reporting-only outer validation;
- five distinct paths: Scratch, Global-best fine-tune, Previous-round fine-tune, Curriculum, and
  Robust loss;
- a committed checkpoint ledger labeled `NPZ + JSON + SHA-256`;
- `Round 0: no history`, `Inner metric only`, `Same current optimizer steps`, and
  `Inherited lineage reported`;
- aggregate-only policy access with no rows, IDs, labels, SMILES, paths, weights, or keys.

The selected final variant is the second checkpoint-lineage correction: it gives the two LOAD
paths visible upward direction and keeps the full ten-module layout stable. The exact machine-
readable arrow contract is duplicated as Mermaid in `docs/architecture.md` and
`docs/inner-loop.md`; those diagrams are authoritative if raster arrowheads are visually
ambiguous at small sizes.

`agentic-active-autoresearch-inner-loop.jpg` (1672 × 941) was regenerated and twice corrected on
2026-08-21. The final prompt required a cyan five-stage outer loop, a violet sequential training
loop, five equal paradigm cards, one-way LOAD arrows from the checkpoint ledger into both
fine-tune paths, one WRITE arrow from selected all-label refit into the ledger, a round-zero
history badge, matched optimizer steps, lineage reporting, an aggregate-only privacy cloud, and a
separate outer-validation reporting lane. A correction pass moved Candidate t+1 feedback to the
candidate generator and removed the checkpoint-direction ambiguity.
